# Prompt şablonları

Sürümlü prompt şablonları bu klasöre eklenecek (Aşama 4), örneğin `free-combination.v1.txt`.

- Kullanıcı hiçbir zaman prompt yazmaz; prompt ürün/kategori metadata'sından sunucuda üretilir.
- Kullanılan şablon sürümü `generation_jobs.prompt_template_version` alanına yazılır.
- Şablon taslağı: [docs/07-ai-entegrasyon.md §4](../../../../../docs/07-ai-entegrasyon.md).
